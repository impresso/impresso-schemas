## ts

timestamp of creation of the JSON file (in '%Y-%m-%dT%H:%M:%SZ' format e.g. '2018-09-18T08:00:08Z')

`ts`

* is required

* Type: `string`

* cannot be null

* defined in: [Audio Record Content Item](audio-record-contentitem-properties-ts.md "https://impresso.github.io/impresso-schemas/json/impresso-2/data-preparation/rebuilt/audio-record-contentitem.v1.schema.json#/properties/ts")

### ts Type

`string`

### ts Constraints

**pattern**: the string must match the following regular expression:&#x20;

```regexp
^[0-9]{4}-[0-9]{2}-[0-9]{2}T[0-9]{2}:[0-9]{2}:[0-9]{2}Z$
```
